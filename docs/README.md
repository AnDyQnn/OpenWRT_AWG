## Коротко о проекте

**Gateway Linux** — это обычный x86‑ПК (старый ноут, неттоп, мини‑ПК), превращённый
в прозрачный межсетевой экран с VPN‑туннелем AmneziaWG (обход DPI). Ставится между
провайдером и домашней/офисной сетью: всё, что за ним, ходит через шифрованный
туннель — без настройки на каждом устройстве.

| | |
|---|---|
| **База** | Debian 12 (mainline‑ядро, драйверы всех NIC) |
| **VPN** | AmneziaWG (amneziawg‑go, компиляция из исходников) |
| **Сервисы** | Docker: `gw-awg`, `gw-dnsmasq`, `gw-webui` |
| **Управление** | веб‑панель HTTPS + консольный `gateway-status` |
| **Размер образа** | ~820 МБ (`.img.gz`) |
| **Лицензия** | MIT |
