# Установка

[← К содержанию](README.md)

Запись образа на флешку и установка на внутренний диск целевого ПК.

> Нужно: целевой ПК с **минимум 2 сетевыми портами**, флешка **≥ 4 ГБ**,
> и второй компьютер чтобы записать флешку.

---

## Шаг 1 — Записать образ на флешку (Rufus)

| Поле Rufus | Значение |
|------------|----------|
| **Устройство** | твоя флешка (всё на ней сотрётся) |
| **Метод загрузки** | → *Выбрать* → указать `gateway.img.gz` |
| **Схема разделов** | GPT |
| **Целевая система** | UEFI (non‑CSM) |

1. Скачай и запусти **[Rufus](https://rufus.ie/)** (portable, установка не нужна).
2. Вставь флешку, выбери `gateway.img.gz`, нажми **СТАРТ**.
3. Подтверди предупреждение «ВСЕ ДАННЫЕ БУДУТ УНИЧТОЖЕНЫ» → **ОК**.
4. Жди ~3–5 минут до статуса «Готов».

> **Про DD‑режим:** для `.img.gz` Rufus пишет в DD‑режиме **автоматически** —
> отдельного окна выбора «ISO / DD» не будет (оно только для `.iso`). Просто
> Старт → ОК → ждать.
>
> **Гибридный образ:** грузится и на современных **UEFI**, и на старых **Legacy
> BIOS**. Если старый ПК не видит флешку — в BIOS выбери Legacy/CSM.

---

## Шаг 2 — Загрузиться с флешки и установить на диск

1. Вставь флешку в **целевой ПК**, включи, зайди в **boot‑меню**
   (`F12` / `F11` / `F8` / `Esc` — зависит от материнки), выбери загрузку с **USB**.
2. Появится меню и **остановится, ожидая ответ**:

```
============================================================
 Gateway Linux  -  Boot menu
============================================================
  Y = INSTALL this system onto an internal disk (recommended)
  N = run LIVE from this USB now (portable, nothing is written)

  Internal disks available for installation:
    [1]  /dev/sdb  [120 GB]  Samsung SSD

  Install to disk? [Y/n] (N = live from USB):
```

| Выбор | Что будет |
|-------|-----------|
| **Y** (или Enter) | установка на внутренний диск |
| **N** | запуск с флешки в live‑режиме (на диск ничего не пишется) |

3. Для установки: **Y** → номер диска → напечатай **`yes`** для подтверждения →
   копирование (~2–3 мин).
4. «Installation finished» → **вытащи флешку** → Enter → ПК перезагрузится с диска.

> Меню — текстом на английском (на этом этапе шрифт консоли ограничен).
> Установленная с диска система это меню **больше не показывает** — только
> live‑флешка. Пароль при вводе в консоли не виден — это нормально.
> Если установщик не появился — войди `root` / `openwrt` и запусти `gateway-install`.

---

## Шаг 3 — Подключить кабели

```
Провайдер ──→ [любой порт ПК]        ← WAN, определится сам
                    ПК
Роутер/ПК  ──→ [любой другой порт]    ← LAN, раздача 192.168.88.x
```

- **Кабель от провайдера** (или его модема/роутера) → в **любой** порт ПК.
- **Любой другой порт** → к домашнему роутеру / коммутатору / компьютеру.
- Какой порт WAN, а какой LAN — шлюз разберётся сам по наличию интернета
  (см. [Сеть и отказоустойчивость](networking-failover.md)).
