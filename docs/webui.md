# Веб‑панель (Gateway Hub)

[← К содержанию](README.md)

FastAPI‑дашборд «межсетевой экран хаб». Доступен по кабелю в LAN, по Wi‑Fi через
роутер за шлюзом и через VPN‑туннель.

**Адрес:** `https://192.168.88.1` · **Логин:** `admin` / `admin`

---

## Вкладки

| Вкладка | Содержание |
|---------|-----------|
| **Дашборд** | Живые метрики со спарклайнами: группы «Железо» (CPU, память, температура, диск I/O) и «Сеть» (WAN/VPN/LAN трафик, число устройств), сводка системы и VPN, блок [**Безопасность**](security.md) (монитор атак: Штатно / Подозрение / Атака, заблокированные адреса) |
| **Сеть** | Интерфейсы (роль WAN / LAN / LAN‑порт / VPN, IP, живая скорость, трафик), [подключённые устройства](segments.md) с режимом выхода (VPN/интернет/локально) и изоляцией, DHCP‑резервирование адресов и имена |
| **VPN** | Статус туннеля, управление, загрузка/скачивание `.conf`, [раздельное туннелирование](vpn-split-tunneling.md) |
| **Доступ** | [Кастомный firewall](access-control.md): группы, блокировки, правила по устройствам, импорт/экспорт; **пользователи** (роли админ / модератор) |
| **Консоль** | Интерактивный терминал самого шлюза (**только администратор**). Вход — **учётными данными панели** (двойная авторизация). Рядом — панель быстрых команд диагностики |
| **Журнал** | События с цветовой подсветкой (OK / WARN / ERR / INFO); сюда же пишутся блокировки fail2ban |
| **Система** | Под‑разделы: [**Безопасность**](security.md) (учётные записи и роли, фаервол, fail2ban, монитор атак, **Консоль и SSH**: пароль root, SSH‑порт, ключи, [резервные копии](backup.md)), [**Обновление**](updates.md) (текущая и доступная версия, накат по кнопке, режимы, прогресс по этапам, ручной откат — только админ), **Справка** (встроенная документация), **О проекте** (автор, GitHub, лицензия) |
| **Документация** | Полная техническая документация (этот раздел) |

## Интерфейс

- **Уведомления** — всплывающие плашки (тосты) справа сверху: зелёные при успехе,
  красные при ошибке. Никаких браузерных `alert`.
- **Подтверждения** — собственные модальные окна (не браузерный `confirm`).
- **Карточки групп и ресурсов** — сворачиваются/разворачиваются кликом по заголовку;
  состояние раскрытия сохраняется при обновлении.
- **Адаптив** — на телефоне таблицы превращаются в карточки, меню — в гамбургер.

## API (для автоматизации)

Все эндпоинты — за cookie‑авторизацией (`POST /api/login`).

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/system` | GET | CPU, RAM, диск, uptime |
| `/api/network` | GET | интерфейсы, роли, трафик |
| `/api/vpn` | GET | статус AmneziaWG |
| `/api/vpn/up\|down\|restart` | POST | управление туннелем |
| `/api/vpn/mode` | POST | `vpn_enable` / `vpn_disable` (persistent) |
| `/api/vpn/config` | POST | загрузить `.conf` (нормализуется + авто‑сбор обхода) |
| `/api/vpn/config-download?which=current\|original` | GET | скачать конфиг |
| `/api/vpn/extract-holes` | POST | собрать обход из дырок ключа |
| `/api/devices` | GET | DHCP‑аренды |
| `/api/access` | GET | весь набор правил + дырки ключа |
| `/api/access/group\|host` | POST | CRUD групп / резервов |
| `/api/access/export\|import` | GET/POST | выгрузка/загрузка правил JSON |
| `/api/split` | POST | CRUD ресурсов раздельного туннелирования |
| `/api/split/export\|import` | GET/POST | выгрузка/загрузка обхода JSON |
| `/api/logs` | GET | журнал событий |

## Журнал

Ведётся в `/var/log/awg-watchdog.log`, обновляется автоматически. Уровни:

| Уровень | Значение |
|---------|----------|
| 🟢 **OK** | успех (VPN восстановлен, туннель поднят) |
| 🟡 **WARN** | предупреждение (VPN недоступен, переключение на прямой) |
| 🔴 **ERR** | ошибка (не удалось поднять туннель, упал сервис) |
| ⚪ **INFO** | информация (ручные действия, старт сервисов) |

Время — местное: NTP + часовой пояс по гео‑IP (по умолчанию Москва).
