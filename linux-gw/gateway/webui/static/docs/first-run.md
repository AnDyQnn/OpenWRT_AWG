# Первый запуск

[← К содержанию](README.md)

> Первый старт **быстрый** — контейнеры уже вшиты в образ, на ПК ничего не
> компилируется.

---

## Порядок

1. Включи ПК с подключённым **кабелем провайдера**.
2. Подожди ~1 минуту — на консоли появится зелёный баннер готовности:

```
✓ GATEWAY ГОТОВ К РАБОТЕ / GATEWAY READY
Веб-панель : https://192.168.88.1   (admin / admin)
Контейнеры : gw-awg gw-dnsmasq gw-webui
```

3. Открой панель: **`https://192.168.88.1`**
   - браузер ругнётся на самоподписанный сертификат → *«Дополнительно» → «Перейти»*
     (это нормально и безопасно в своей сети);
   - логин **`admin`** / пароль **`admin`**.
4. Вкладка **VPN** → загрузи свой `.conf` AmneziaWG (файлом или текстом).
5. 🟢 Готово — весь трафик за шлюзом идёт через зашифрованный туннель.

> Интернет нужен только для самого VPN‑трафика, **не** для первого запуска.

---

## Доступы по умолчанию

> ⚠ Это **стандартные пароли образа** — их видят все, кто скачал.
> **Смени оба после установки.**

| Что | Адрес | Логин | Пароль |
|-----|-------|-------|--------|
| **Веб‑панель** | `https://192.168.88.1` | `admin` | `admin` |
| **Встроенная консоль** (вкладка «Консоль») | в браузере | `admin` | `admin` (креды панели) |
| **SSH** (внешний клиент) | `ssh -p 23232 root@192.168.88.1` | `root` | `root` |

> **SSH на порту 23232** (не стандартный 22 — меньше шума-перебора) и доступен
> **только из локалки/VPN**: снаружи фаервол его закрывает. См. [Безопасность](security.md).

> **Важно про консоль.** Встроенная **Консоль** в панели спрашивает **те же
> учётные данные, что и сама панель** (`admin` / `admin` по умолчанию) — не нужно
> помнить отдельный пароль. Пароль `root` нужен только для входа по
> **внешнему SSH-клиенту**.

- Пароль и учётки панели (а значит и вход в консоль) — вкладка **«Система → Безопасность»**:
  смена логина/пароля, создание учёток, сброс пароля администратором.
- Пароль **root** для внешнего SSH, смена SSH-порта и **SSH-ключи** — там же,
  карточка **«Консоль и SSH»** (ключ можно сгенерировать прямо в панели). См.
  [Безопасность](security.md).

## Адреса доступа к панели

Адрес `192.168.88.1` стабилен при **любом** способе подключения:

| Откуда подключаешься | Адрес панели |
|----------------------|--------------|
| Кабель в LAN‑порт шлюза | `https://192.168.88.1` |
| Wi‑Fi через роутер за шлюзом | `https://192.168.88.1` |
| Через VPN‑туннель | `https://192.168.88.1` |
| С самого ПК‑шлюза (консоль) | команда `gateway-status` |

HTTPS, самоподписанный сертификат — порт указывать не нужно.

---

## Консольный дашборд

На самом ПК (или по SSH) — быстрый обзор без браузера:

```sh
gateway-status            # один снимок
watch -n3 gateway-status  # авто-обновление
```

Показывает: систему, WAN/LAN‑порты и их IP, режим VPN, хэндшейк,
Docker‑контейнеры, DHCP‑аренды, последние события. Если контейнер не `Up` —
печатает его последние строки лога **прямо на экране** (видно причину сбоя).
